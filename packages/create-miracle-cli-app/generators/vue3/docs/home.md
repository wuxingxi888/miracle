# 介绍

### 关于

这是一个基于 Miracle CLI 初始化的 Vue 3 移动端组件项目模板，适合用来沉淀中后台 H5 页面里的业务组件、交互模式和主题规范。

### 默认包含

-   一个可以直接启动的组件示例与文档站点
-   基于 `miracle.config.mjs` 的站点导航与构建配置
-   可按需切换的 `<%= preprocessor %>` 样式预处理器
-   适合继续扩展主题变量、场景页面和业务组件文档的目录结构

### 下一步建议

1. 在 `src` 下新增业务组件或场景页。
2. 在 `docs` 中补充接入说明、设计约束和最佳实践。
3. 通过 `ConfigProvider` 统一主题变量与暗黑模式策略。
