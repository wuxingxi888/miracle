# 项目定位

### 我们在解决什么问题

Miracle UI 的目标不是单纯提供“越多越好”的基础组件，而是帮助 Vue 3 的移动业务团队更快搭建一致、可维护、可发布的 H5 页面。

### 对谁最有价值

-   需要沉淀业务组件和页面模式的团队
-   需要统一表单、筛选、选择器、上传、导航交互的项目
-   希望通过主题变量和文档站形成长期规范的组件库维护者

### 对谁不是最佳选择

-   主要做桌面端后台和复杂表格的项目
-   需要跨端渲染或原生能力封装的项目
-   更适合一次性接入完整企业级设计系统的团队

### 与常见组件库的差异

-   更强调移动业务 H5 场景，而不是桌面端通用能力
-   更强调场景组合与推荐组合方式，而不只是单个组件文档
-   更强调主题变量、暗黑模式、发布节奏等工程化约束

### 我们的优先级

1. 先把高频业务场景做顺手
2. 再补足关键基础能力短板
3. 最后再考虑更大范围的平台化扩展
